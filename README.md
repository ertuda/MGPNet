R scripts for the topological and coexpression analysis of mutual gene pairs are provided in the repository. Two different scripts could be used to analyze the human Gene Regulatory Network (GRN) and Protein Signaling Network (PSN). ReduceExp script could be used to simplify gene/protein expression dataset expression values such that only the genes for interaction information is retained and multiple ids for a single gene is averaged. The reduced expression datasets that were used in the project could be found in the repository. A supplementary table of all differential correlation values is also provided. The online application, MGPNet, based on Shiny R, could be used to analyse the mutual gene pairs (http://konulabapps.bilkent.edu.tr:3838/MGPNet/). The R and html files for the MGPNet application are also provided.
